# celo-mento-arb

Arbitragem experimental usando Mento V3 e Aave V3 na Celo.

## Aviso

Este código é experimental. Não use em mainnet sem auditoria,
testes fork, validação dos endereços e proteção contra slippage.

## Comandos

```bash
forge install foundry-rs/forge-std --no-commit
forge install OpenZeppelin/openzeppelin-contracts --no-commit
forge install aave/aave-v3-core --no-commit

forge build
forge test -vvv
```

## Rede

- Celo Mainnet
- Mento V3
- Aave V3
